# Каток 2.0 — большой путь

Мобильная веб-игра: один свайп двигает все шайбы. Соберите каждую в лунку её цвета.

## Что изменилось

500 уровней вместо 60. Единая непрерывная дорожка без миров и зон. На льду убрана зональная разметка. Новый интерфейс, индикатор общего прогресса, возврат к текущему уровню, кнопки направлений в дополнение к свайпам. Сложные уровни отмечены ромбом.

Из «Тянучек» использован подход к кампании: 500 заданий, постепенное увеличение поля и числа элементов, подготовка и проверка уровней вне телефона. Механика движения и решатель остаются собственными для «Катка»; обратный генератор блоков «Тянучек» сюда напрямую не переносился.

Первые 60 полей и их номера сохранены. Прогресс продолжает использовать ключ `katok.v1` на прежнем адресе сайта. Новый адрес или другой браузер имеют отдельный прогресс.

## Запуск

Откройте `index.html` на компьютере для быстрой игры. Для установки на iPhone и офлайн-работы разместите файлы в корне GitHub Pages. В Safari откройте сайт, выберите «Поделиться → На экран Домой», затем запустите с иконки при включённом интернете и дождитесь загрузки. После обновления закройте игру и откройте снова с интернетом; при необходимости повторите.

Это веб-приложение, не нативная iOS-сборка. Очистка данных сайта может удалить прогресс и офлайн-копию.

## Проверки

`node scripts/verify-levels.cjs` проверяет уникальность 500 полей, воспроизведение каждого решения, связность новых полей и поиск более короткого решения с ограничением перебора. При генерации кратчайшие решения найдены BFS.

`node scripts/generate-levels.cjs` заново создаёт уровни 61–500 из фиксированного seed и обновляет встроенные данные `index.html`; первые 60 остаются прежними. Генератор работает при подготовке игры, а не на iPhone.

Проверены в браузере запуск, прохождение первого уровня, награда и разблокировка следующего, сохранение после перезагрузки, подсказка, отмена и перезапуск. Нужны проверки на физическом iPhone: свайпы, маленький экран, работа в авиарежиме и обновление уже установленной копии.
